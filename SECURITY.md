# Security policy

## Scope

This repository contains the m-sign format specifications and test vectors. Security issues in the specifications themselves are in scope, for example a requirement that allows forgery, key recovery or ambiguous parsing. For problems in an implementation, report to the implementation's repository: [m-sign/msign](https://github.com/m-sign/msign) or [m-sign/tools](https://github.com/m-sign/tools).

## Supported versions

| Version | Supported |
|---|---|
| 1.x | Yes |

## Reporting a vulnerability

Do not open a public issue. Report privately, by either of these:

- GitHub private vulnerability reporting: the "Report a vulnerability" button on this repository's Security tab.
- Email: `as[.]m[.]github-report[@]melnyk[.]org` (replace `[.]` with `.` and `[@]` with `@`).

Please include the affected document and version, a description of the issue, and, where possible, a proof of concept or test vector.

We aim to acknowledge reports within 7 days. We will agree on a disclosure date with you and credit you in the advisory unless you prefer otherwise.
